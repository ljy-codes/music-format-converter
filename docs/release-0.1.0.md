# 音乐格式转换器 v0.1.0 — 源码预发布

## 功能

- 中文离线桌面界面；添加文件/文件夹、拖放、导入即列出候选音乐、显式预检后转换。
- 智能保真、ALAC、AAC、MP3、FLAC、WAV 六种模式；保留原文件，不覆盖已有输出。
- 单项进度、取消、失败重试、JSON/CSV 报告；Windows 自包含安装包/便携包构建脚本。

## 修复

- 不支持、未执行转换的项目显示“已跳过”，不再误报“失败”，并与失败/取消分别统计。
- WMA Lossless 缺失位深识别、TAK 单声道 AAC 布局、WMA 转 AAC 时间戳问题。
- 取消时临时文件清理有界重试；持续占用时明确提示残留，不误报已清理。

## 验证

Windows 141 项自动化测试通过；26 样本 × 6 模式 × CLI/原生 UI 共 312 场景分类符合预期；23 项边界用例通过。成功输出独立解码和校验。详见 `verification.md`。

## 兼容性

新增 `Skipped` 终态及 JSON `skipped` 计数；旧枚举数值不变，严格状态读取器需适配。CLI 退出 1 仍表示有未处理项（失败或跳过），不等于所有未处理项均转换失败。

## 下载范围与已知限制

**本次为源码 Release，不是完整安装包的公开发布。** 附件提供项目源码 ZIP 和 SHA256；不包含 FFmpeg 引擎、.NET 运行库、本地测试报告或网络音频。

本地 Windows 安装包与便携包已完成构建和验证，但捆绑组件的第三方许可/完整源码分发审核尚未完成，因此不随本次公开 Release 上传。根目录 MIT 许可只覆盖项目自有代码。

Mac 真机、Apple Music 导入播放、签名/公证与实际安装升级/卸载仍待验收。没有自动触发 GitHub Actions 或上传 Apple 公证。
