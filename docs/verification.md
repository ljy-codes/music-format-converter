# 0.1.0 公开验证摘要

验证日期：2026-10-08。平台：Windows x64，.NET SDK 10.0.400，固定离线引擎。本文不含用户路径、真实歌曲名称或下载音频；详细日志及报告仅保留在本地。

## 本次修复

- 预检已确定 Unsupported、未执行转换的项目改为 `Skipped` / “已跳过”，保留原因，单独统计，不参与失败重试。
- 真实执行阶段的源检查、解码、编码和输出校验异常仍是 `Failed`。
- 取消和 UI 批次异常补齐结果也保持上述区分。
- JSON/CSV 支持 Skipped；JSON 增加 skipped 计数。

修改范围：Core 的 Models、MusicConverter、ReportWriter；App 的 QueueItemViewModel、WorkspaceViewModel；CLI Program；相关回归测试及文档。音质策略、编码参数、默认模式、安装标识不变，无数据库或远程服务变更。

## 兼容性与边界

- `ItemStatus.Skipped=5` 为追加值，原有 0～4 保持不变。
- 报告 `schemaVersion` 仍为 1，增加字段和状态值；严格限定旧状态枚举的读取程序需要适配。
- CLI：0 全部成功，1 有失败或跳过，2 全局错误，130 取消。
- 未自动安装或覆盖已安装程序；本轮不把“生成安装包”表述为安装升级/卸载验收。
- Windows 包未代码签名；Mac 真机、Apple Music 实际导入播放未验收。
- Windows 捆绑引擎第三方依赖的完整许可/源码分发审核尚未完成。公开 Release 仅提供项目源码，不含本地完整二进制、运行库或引擎；详见 `engine-provenance.md` 和根目录 `THIRD-PARTY-NOTICES.md`。
